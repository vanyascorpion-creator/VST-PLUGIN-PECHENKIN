\# MySynth



MySynth — полифонический VST3-синтезатор для Windows и FL Studio.



\## Возможности



\- два осциллятора;

\- формы волны Sine, Saw, Square и Triangle;

\- громкость каждого осциллятора;

\- расстройка второго осциллятора;

\- ADSR-конверт;

\- low-pass-фильтр;

\- параметры Cutoff и Resonance;

\- поддержка MIDI;

\- сохранение параметров в проекте DAW;

\- формат VST3;

\- 64-bit Windows.



\## Установка готовой версии



1\. Откройте страницу \*\*Releases\*\* этого репозитория.

2\. Скачайте файл `MySynth-Setup.exe`.

3\. Запустите установщик.

4\. Подтвердите установку с правами администратора.

5\. Перезапустите FL Studio.

6\. Откройте:



&#x20;  `Options > Manage plugins`



7\. Нажмите `Find installed plugins`.

8\. Найдите `MySynth` среди генераторов.
